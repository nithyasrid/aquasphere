# 🌿 AquaSphere Lite

**Water • Soil • Life**

Demo : [https://gleeful-dasik-b9335c.netlify.app/](https://gleeful-dasik-b9335c.netlify.app/)

A nature-themed educational web application combining three groundwater-awareness experiences:

-  **AquaQuest** — interactive conservation game inspired by the educational-game direction of SIH1698.
-  **AquaBot** — curated groundwater information assistant inspired by SIH1697.
-  **AquaPredict** — transparent educational groundwater-risk index inspired by SIH1696.

## Core idea

**Observe → Understand → Predict → Act → Learn**

The app is intentionally lightweight and runs entirely in the browser.

## Features

### AquaQuest
Five scenarios:
1. Household leakage
2. Efficient irrigation
3. Rainwater harvesting
4. Recharge-zone protection
5. Household conservation

Choices change eco points, estimated water saved, groundwater, ecosystem health and the visual garden state.

### AquaBot
Answers common questions about groundwater, recharge, aquifers, rainwater harvesting, groundwater decline and conservation using a curated local knowledge base.

### AquaPredict
Inputs:
- Annual rainfall
- Water extraction
- Average temperature
- Season

Outputs:
- Groundwater outlook score
- Recharge potential
- Extraction pressure
- Suggested conservation action

**Important:** AquaPredict is an educational index, not a validated scientific forecasting model.

## Demo flow

1. Introduce groundwater pressure.
2. Play two or three AquaQuest scenarios.
3. Show groundwater/ecosystem meters changing.
4. Ask AquaBot two questions.
5. Change rainfall/extraction/temperature in AquaPredict.
6. Explain the unified loop: **Understand → Predict → Act → Learn**.
